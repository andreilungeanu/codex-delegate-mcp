# Writing

Applies to docs, comments, CHANGELOG entries, and every string that ships to an agent.

- Describe what something does, not what it lacks. `Auto-approved in every mode`, not
  `unsandboxed` / `there is no containment` / `nothing prompts`. Same fact, spec voice
  rather than confession.
- Keep every fact when re-voicing. A tone pass that quietly drops information is a
  regression, not a rewrite.
- Text that ships into an agent's context — `SERVER_INSTRUCTIONS`, tool and field
  descriptions, `skills/` — is paid for on every session. State a thing once, in the layer
  that owns it. If one layer grows, another cuts.
- No epigrams written to sound wise, no florid metaphor, no synonym reached for to dodge a
  word. Plain sentences a reader can act on.
- Match `cursor-delegate-mcp`. The two plugins should read as one product, so mirror its
  construction where they describe the same thing.
- Historical records are not rewritten. `docs/` and released CHANGELOG entries state what
  was true when written; correct them only where they misstate it.
